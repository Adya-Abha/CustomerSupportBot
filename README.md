# Customer Support Bot

## 📌 Problem Statement
Customers often struggle to get quick answers to FAQs. This bot provides instant responses and escalation to human agents when needed.

## 🚀 Setup Instructions
1. Open the Web Demo link: [Dialogflow Bot Demo](https://console.dialogflow.com/api-client/demo/embedded/93ab0d0e-a885-4f59-b393-9deb10a20501)  
   ⚠️ If you see a certificate warning, click **Advanced → Proceed**.
2. To run locally:
   - Clone this repo
   - Open `index.html` in a browser to see the embedded bot
